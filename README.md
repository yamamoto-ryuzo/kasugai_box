# Box Photo Geo URL

Boxのフォルダ内の画像ファイルを取得し、EXIF情報から緯度経度・撮影日を抽出し、共有リンク付きで一覧化・GeoJSON/CSV出力するRustツールです。

注意: 画像のEXIF情報は画像ファイル自体に埋め込まれているため、画像本体の取得（ダウンロード）が必要です。Box APIは画像のEXIFをメタデータとして返しません。

## 特徴

- Box APIで指定フォルダ（サブフォルダ含む）内の画像ファイルを再帰的に取得
- 画像のEXIF情報から緯度・経度・撮影日を抽出（JPEG/TIFF/HEIC対応）
- 画像ごとにBoxの共有リンク（Web URL）を付与
- 結果を `output` フォルダ内にCSVおよびGeoJSON（QGIS対応）で出力
- QGISで「url」列を使ってアクションやHTMLポップアップで写真表示が可能

## 🎯 利用者の方へ

プログラミング環境をお持ちでない方は、以下の手順ですぐに利用を開始できます。

### 1. ダウンロード
GitHubからツールをダウンロードします。以下のどちらかの方法で取得してください。
- **Releasesから取得**: 右側の **[Releases]** (または最新のReleaseタグ) をクリックし、アセット一覧からZIPファイルなどをダウンロードして解凍します。
- **リポジトリをそのままダウンロード**: 右上の緑色のボタン「Code」から「Download ZIP」を選んでダウンロードし、解凍します。（解凍後、中にある `bin` フォルダを開いてください）

### 2. ツールの実行
1. 取得・解凍したフォルダ内にある実行ファイル（`bin` フォルダの中の `box_photo_geo_url_rs.exe`）をダブルクリックして実行します。
2. 初回起動時は、黒い画面（コマンドプロンプト）が開くので、画面の指示に従って Box の `開発者トークン` と `対象フォルダURL` を入力してください。
   - （※入力内容は同じフォルダに `config.json` として自動保存されるため、次回以降は入力不要です。）
3. 指定フォルダ以下の画像ファイルを再帰的に取得し、EXIF情報から位置情報・撮影日を抽出します。
4. 処理が完了すると、実行ファイルと同じ場所に `output` フォルダが作成され、その中に結果ファイルが保存されます。

### 3. 出力ファイル
実行ファイルの配置場所を基準とした `output` フォルダ内に以下のファイルが作成されます。
- `output/box_photos.csv`  
  画像ファイル名、パス、緯度、経度、撮影日、Box共有URLを含むCSV
- `output/box_photos.geojson`  
  QGIS等で利用できるGeoJSONファイル（EPSG:4326、url列付き）

### 4. QGISでの利用例
- 「url」列をQGISの「アクション」や「HTMLポップアップ」で利用し、写真をWeb表示できます。
  - 例: アクションに `[% "url" %]` を設定しWebブラウザで画像を開く
  - 例: HTMLポップアップに `<img src="[% "url" %]" width="400">` など

## 💻 開発者向け情報

Rust環境がある場合は、ソースコードからの直接実行やビルドが可能です。

### ソースコードからの実行
リポジトリのルートで以下を実行します。

```sh
cargo run
```
この場合、`config.json` や `output` フォルダはプロジェクトのルートディレクトリに生成されます。

### EXEファイルのビルドについて
ご自身でソースコードからビルドし直す場合は、以下のコマンドを実行します。

```sh
cargo build --release
```

ビルドが完了すると、`target/release/box_photo_geo_url_rs.exe` に実行ファイルが生成されます。これを任意のフォルダ（`bin`など）にコピーしてご利用ください。

---

## ⚠️ 注意事項

- 画像のEXIF情報は画像ファイル自体に埋め込まれているため、**画像をダウンロードせずにEXIF情報を取得することはできません**。
- Box APIは画像のメタデータとしてEXIF情報を直接返すエンドポイントを提供しません。
- EXIFのGPS情報はWGS84（EPSG:4326）を前提としています。
- `access_token` の有効期限切れ時は再取得が必要です。
