Box API 接続

Box API を利用したチャット接続です。詳細な使い方は「APIヘルプ」タブを確認してください。

MCP 接続

MCP サーバーに接続し、ツール一覧の取得と実行ができます。設定は「管理」タブの「設定」で行ってください。


      


      

        
APIヘルプ

        
    
          
  • この接続は Box API を使用しています。
    • 
          
  • 利用可能なコマンド: help / me / folder <id> / search <q>
    • 
          
  • コマンドと引数は半角スペースで区切ってください。
    • 
          
  • 全角スペース（　）は検索語の一部として扱われます。
    • 
          
  • コマンドなしで単語だけ入力した場合、自動的に search として扱われます。
    • 
          
  • search は Box 標準検索です。ファイル名・メタデータ・文書内テキストを対象に返します。
    • 
          
  • 検索結果は 100 件ずつ取得し（設定で 1〜200 件変更可）、Enter を押すと次の件数を読み込みます。
    • 
          
  • 複数単語を空白区切りで入力した場合、デフォルトは OR 扱いです。
    • 
          
  • AND / OR / NOT は大文字で指定してください。
    • 
          
  • "phrase" のようにダブルクォートで囲むと、フレーズ完全一致検索になります。
    • 
        

        
REST API / MCP

        
    
          
  • この画面のすべての機能は REST API（OpenAPI 仕様）から利用できます。
    • 
          
  • AI エージェントからは POST /mcp（Streamable HTTP）で同じ機能をツールとして利用できます。
    • 
          
  • ヘルスチェック: GET /health
    •
